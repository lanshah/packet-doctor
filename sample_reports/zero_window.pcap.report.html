How Packet Doctor reaches its conclusions

TCP flags (retransmission, duplicate ACK, zero window, out-of-order …) follow the same rules as Wireshark's TCP analysis, so frame numbers here match Wireshark's Expert Info. Each problem is written up with the Kepner-Tregoe method: describe what IS and IS NOT affected, list candidate causes, drop any cause that contradicts the IS-NOT side, and prefer the one needing the fewest assumptions. Confidence is lowered when evidence is thin or capture artefacts are present. Thresholds used: retransmissions ≥ 1.0% of a sender's segments (and at least 3 in total), handshake RTT ≥ 300 ms, server time ≥ 500 ms, DNS ≥ 200 ms, DNS timeout 2.0 s.
